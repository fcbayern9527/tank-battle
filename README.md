# 🛡️ 坦克大战 (Tank Battle)

一个用原生 HTML5 Canvas 编写的经典「坦克大战 / Battle City」风格小游戏，单个 `index.html` 文件，无需任何依赖，双击即可游玩。

## 玩法

- 操控己方坦克，击毁所有来袭的敌军坦克，并守住自己的基地 🏰
- 基地被摧毁、或我方生命耗尽即游戏结束
- 每关敌军数量随关卡递增，通关后进入下一关

## 操作

| 按键 | 功能 |
| --- | --- |
| `← ↑ ↓ →` 或 `W A S D` | 移动 |
| `空格` / `J` | 开炮（可按住连发） |
| `P` / `Esc` | 暂停 |
| 触屏设备 | 屏幕上的虚拟方向键 + 开炮按钮 |

## 游戏元素

- 🧱 **砖墙**：可被摧毁（普通炮弹两发，升级后一发）
- ⬜ **钢墙**：不可摧毁（满级火力可击穿）
- 🌊 **水域**：阻挡坦克，但子弹可穿过
- 🌿 **草丛**：隐藏坦克（可穿过）
- 🏰 **基地**：务必守住

## 道具（击毁特定敌军随机掉落）

- ★ 火力升级（最多 2 级，满级可击穿钢墙）
- 🛡 护盾（短暂无敌）
- ♥ 生命 +1
- 💣 全灭当前屏幕上的敌军
- ⏱ 冻结敌军

## 运行

直接双击打开 `index.html`，或用任意静态服务器：

```bash
# 二选一
npx serve .
python -m http.server 8000
```

然后浏览器访问对应地址即可。
